# important commands
## open serial terminal
```
idf.py -p /dev/ttyUSB0 flash monitor
```
- compile the project
- flash firmware
- open serial monitor

|shortcut|action|
|-------|------------|
|cntrl+]|exit monitor|
|cntrl+T|options menu|
|cntrl+T + cntrl+H|show all shortcuts|
|cntrl+T + cntrl+R|reset firmware|
|cntr+T + cntrl+F|recompile and reflash without exiting the monitor|
|cntrl+T + cntrl+Y|stop/restart the logs on the monitor|
